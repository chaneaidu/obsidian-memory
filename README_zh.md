# Obsidian Memory

**AI 的持久记忆** - 捕捉你的 Obsidian 工作，生成 AI 可读的内存，并在 AI 对话中注入上下文。

[English Version](README.md)

---

## 问题所在

当你与 AI（Claude、ChatGPT 等）聊天时，每次对话都是从零开始。AI 对以下内容一无所知：

- 你当前的项目架构
- 你最近做出的决策
- 你工作中的重要发现

尽管你已经将所有内容记录在 Obsidian 中，但没有简单的方法让 AI 获取这些上下文。

## 解决方案

**Obsidian Memory** 桥接了这个鸿沟 - 它将你的 Obsidian 工作转化为 AI 可以理解和使用的持久记忆。

```
你在 Obsidian 中工作 → 插件捕捉观察 → 你注入上下文到 AI → AI 理解你的上下文
```

---

## 核心功能

| 功能 | 描述 |
|------|------|
| **自动捕获** | 每 30 秒检测一次 vault 中的文件变化（可配置） |
| **AI 叙事生成** | 使用 MiniMax API 生成自然语言描述 |
| **本地存储** | 保存到 `memories.json` - 跨会话持久化 |
| **搜索与筛选** | 关键词搜索，支持时间筛选 |
| **手动笔记** | 不仅自动捕获，也可手动添加想法 |
| **上下文注入** | 一键复制格式化的内存到剪贴板 |

## 使用场景

### 1. AI 辅助开发

```
1. 你在 Obsidian 中编辑代码笔记
2. 插件生成观察描述（"实现了用户认证模块"）
```

```
1. 文件编辑自动生成观察

```

## 安装

### 前置要求

- Obsidian v1.5.0 或更高版本
- MiniMax API 密钥（用于 AI 叙事生成）

### 步骤

1. 从 releases 下载 `main.js`、`manifest.json`、`styles.css`
2. 将它们放入 `{vault}/.obsidian/plugins/obsidian-memory/`
3. 在 Obsidian 设置 → 插件中启用插件
4. 在插件设置中配置你的 MiniMax API 密钥

### 获取 MiniMax API 密钥

1. 访问 [MiniMax API](https://api.minimax.chat/)
2. 注册并获取 API 密钥
3. 粘贴到插件设置中

## 使用方法

### 打开 Memory Panel

- 点击左侧边栏的灯泡图标
- 或使用命令面板（Ctrl/Cmd+P）→ 搜索 "Memory"

### 手动添加记忆

1. 点击顶部的 **"+"** 按钮
2. 填写标题、内容、类型、概念
3. 点击"保存"

### 搜索记忆

1. 在搜索框中输入关键词
2. 按回车键
3. 使用时间筛选器（全部/今天/本周/本月）

### 注入上下文到 AI

1. 开始一个 AI 对话
2. 点击面板中的 **"📋"** 按钮
3. 记忆复制到剪贴板
4. 粘贴到 AI 对话中

### 删除记忆

- 悬停在任意记忆上 → 出现红色"删除"按钮

### 导出

- 点击底部的"导出记忆" → 所有记忆 JSON 复制到剪贴板

## 隐私

- **本地存储** - 所有数据保存到本地 `memories.json`
- **AI 通信** - 只有观察（不是文件内容）发送到 MiniMax API
- **你控制** - 随时可以禁用自动捕获，仅手动记录
- **无追踪** - 插件不收集任何使用数据

---

## 配置

| 设置 | 描述 | 默认值 |
|------|------|--------|
| API 密钥 | MiniMax API 密钥 | （必填） |
| 轮询间隔 | 扫描 vault 的间隔秒数 | 30 |
| 自动捕获 | 自动捕获文件变化 | true |
| 默认时间筛选 | 默认视图筛选 | 全部 |

## 常见问题

### 问：如何获取 API 密钥？
访问 [MiniMax API](https://api.minimax.chat/) 注册获取。

### 问：为什么 AI 生成失败？
1. 检查 API 密钥是否配置正确
2. 检查网络连接
3. API 有速率限制 - 等待后重试

### 问：数据存储在哪里？
`{vault}/.obsidian-memory/memories.json`

### 问：如何禁用自动捕获？
在设置中关闭"自动捕获" - 插件将只记录手动添加的记忆。
