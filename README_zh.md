# Obsidian Memory

**AI 的终身记忆** — 将 Obsidian 笔记转化为持久的、可注入的上下文，让 AI 真正理解你的世界。

[English Version](README.md)

---

## 问题所在

每次 AI 对话都是从零开始。AI **完全没有记忆**：
- 你的代码库架构决策
- 最近的项目发现
- 过去的问题解决方法

尽管一切都在 Obsidian 中有记录，AI 却无法访问 — 这造成了巨大的上下文鸿沟，浪费你的时间不断重复背景信息。

## 解决方案

**Obsidian Memory** 用一套完整的系统来弥合这个鸿沟：

```
你在 Obsidian 中工作 → 自动捕捉上下文 → AI 理解你的世界
```

**三种注入方式：**
1. **📋 手动复制** — 一键复制格式化记忆
2. **🌐 浏览器扩展** — 一键自动注入到 Claude/ChatGPT
3. **🔌 API 访问** — 供 AI 工具和脚本程序化访问

## 快速开始

### 1. 安装插件

复制到 Obsidian 插件文件夹：
```bash
# 你的 vault 路径
{vault}/.obsidian/plugins/obsidian-memory/
# 复制：main.js, manifest.json, styles.css
```

在 Obsidian 设置 → 插件 → 启用 **Memory**

### 2. 配置 API 密钥

设置 → Memory → 输入你的 API 密钥（MiniMax 或兼容 API）

### 3. 开始使用

- **打开面板**：点击侧边栏 🧠 或 `Ctrl/Cmd+P` → "Memory"
- **自动捕捉**：自动工作 — 正常使用 Obsidian 即可
- **手动添加**：点击 **+** 手动添加想法
- **搜索**：输入关键词 + 时间筛选（今天/本周/本月）
- **注入**：点击 **📋** 复制，粘贴到任意 AI

## 进阶：浏览器扩展 + API 服务器

### API 服务器（可选）

用于程序化访问或浏览器扩展：

```bash
node server/index.js "/path/to/vault"
# 运行在 http://localhost:9180
```

**端点：**
| 方法 | 端点 | 描述 |
|------|------|------|
| GET | `/health` | 健康检查 |
| GET | `/memories` | 所有记忆 |
| GET | `/memories/recent?limit=10` | 最近记忆 |
| GET | `/memories/search?q=xxx` | 搜索记忆 |

### 浏览器扩展（可选）

1. 打开 `chrome://extensions/`
2. 启用开发者模式
3. 加载已解压 → 选择 `extension/` 文件夹
4. 访问 Claude.ai 或 ChatGPT — 🧠 按钮出现

## 功能

### 核心功能
- **自动捕捉**：每 30 秒检测文件变化（可配置）
- **AI 叙事生成**：将文件变化转换为可读摘要
- **本地存储**：所有数据在 `memories.json` — 无云端，无追踪
- **隐私保护**：只发送观察给 AI，绝不发送原始文件内容

### 搜索与筛选
- 全文关键词搜索
- 时间筛选（全部/今天/本周/本月）
- 相关性评分结果

### 手动记忆
- 添加非文件来源的想法
- 用概念标签
- 按类型分类（change/bugfix/feature/decision）

### 导出
- 复制所有记忆为 JSON
- 复制格式化记忆用于 AI 提示词
- 单条记忆删除

## 隐私

- **仅本地**：所有数据存储在你的 vault 的 `.obsidian-memory/` 文件夹中
- **无云端**：除了你选择的 AI API 外，不发送任何内容到外部服务器
- **你控制**：随时禁用自动捕捉 — 仅手动模式
- **零遥测**：零追踪、零分析

## 常见问题

**问：哪些 AI API 可以用？**
答：任何 OpenAI 兼容 API。默认是 MiniMax。在设置中配置 URL 和模型。

**问：数据如何存储？**
答：`{vault}/.obsidian-memory/memories.json`

**问：为什么浏览器扩展需要服务器？**
答：浏览器扩展无法直接读取本地文件。服务器读取 `memories.json` 并通过 HTTP 提供服务。

**问：如何禁用自动捕捉？**
答：设置 → 自动捕捉 → 关闭。插件只记录手动添加的记忆。
